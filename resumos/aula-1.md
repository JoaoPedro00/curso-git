| Comando | Ação |
|----------|--------|
| `git cd` | mudar de diretorios |
| `git init` | iniciar repositorio git |
| `git status` |verificar o status do repositorio |

**3 Formas de adicionar arquivos do working directory para a staging area**
- git add {nome do arquivo} -> add um arquivo
- git add *.{extensao dos arquivos} -> add varios arquivos do mesmo tipo
- git add . -> add todos os arquivos 


**Mover os arquivos da staging area para o git directory**
git commit -m"{mensagem sobre o commit}

aqruivo .gitignore -> nome de arquivos e diretoriosque voce quer ignorar
